# Player Manager

A command-line application built with Python to manage a list of players. This project focuses on practicing Python fundamentals through an interactive menu and player management operations.

## Features

- Add players
- Display players
- Search for players
- Delete players
- Interactive command-line menu

## Technologies 
- Python

## What I Practiced

- Lists and list methods
- "append()" and "remove()"
- "for" and "while" loops
- Conditional statements ("if", "elif", and "else")
- User input ("input()")
- List length ("len()")
- Menu-driven program logic
- Basic program structure

## About 

This project was created to practice Python fundamentals by building a simple player management application. It documents my learning progress through the practical use of lists, loops, conditionals, and user input.
